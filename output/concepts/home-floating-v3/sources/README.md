# Botanical sidebar icon concepts

Generated with the built-in image_gen tool and approved for Home, 20 November 2026.
These are unchanged source masters. Runtime 128px exports are packaged by
tools/package_home_navigation.py into assets/home-navigation/v1. Masters and
generation prompts stay outside the app bundle.

- Shop: ochre canvas shopping bag with a green leaf.
- Catalog: sage botanical journal with cream pages and a gold clasp.
- Packs: sealed cream-and-sage seed booster packet with a sprout.
- Milestones: gold checkmark medal with sage ribbon tails.
- Expedition: parchment map with green mountains and a gold compass arrow.

All five original PNGs retain their generated RGBA transparency, 1254 × 1254
pixels. They share soft matte surfaces, subtle facets and a restrained botanical
palette chosen to fit the game's existing quantity artwork. Text and exclamation
badges are intentionally separate UI elements, not baked into the icon images.

The v3 mockups display each image on a 36-point canvas, with an 11-point outlined
live label slightly overlapping its lower edge. Targets are 60 × 44 points with
no translucent panel. Production exports have been downsampled with preserved
alpha; native device checks remain pending. The source PNGs here are unchanged;
no background replacement was performed.

See generation-prompts.json for the complete per-image prompts and provenance.
